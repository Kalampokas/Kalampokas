# George Kalampokas — Smart Home & IoT Systems Integrator

Σχεδιάζω και υλοποιώ **τοπικά, αυτόνομα συστήματα αυτοματισμού κτιρίων (Local-First Smart Home & Security)** βασισμένα στο **Home Assistant**, χωρίς εξάρτηση από cloud servers τρίτων.

Εστιάζω στην αξιοπιστία σε επίπεδο hardware και δικτύου, στην ενοποίηση ετερογενών υποσυστημάτων (φωτισμός, κλιματισμός, ασφάλεια, διαχείριση ενέργειας) και σε καθαρά, mobile-first περιβάλλοντα χρήσης.

---

### Τεχνικό Stack & Αρχιτεκτονική

* **Core Platform:** Home Assistant OS (Bare-metal / Mini PC), YAML, Jinja2, Diagnostics & Trace Debugging
* **Local Protocols:** Zigbee (ZHA & Zigbee2MQTT), MQTT, ESPHome, Modbus / Local APIs
* **Security & Safety:** Alarmo, Physical Keypads (Zigbee), Leak/Smoke Detection, iOS Critical Alerts
* **Custom Hardware & Nodes:** ESP32 / ESP8266, I2C OLED Displays, Environmental & mmWave Presence Sensors
* **Remote Access & Resilience:** Tailscale VPN, Automated Offsite Backups, UPS / Battery Protection Logic
